# Atividades de padrões de projeto — código inicial

Projeto Java (JDK 17 ou superior), organizado em três pacotes independentes. **Este repositório contém pontos de implementação pendentes de três padrões de projeto**; não é uma solução completa.
- **A5 — `factory` (Abstract Factory)**
- **A6 — `adapter` (Adapter)**
- **A7 — `strategy` (Strategy)**

## Execução

Compile com `mvn compile` e execute individualmente `padroes.projeto.factory.Main`, `padroes.projeto.adapter.Main` e `padroes.projeto.strategy.Main` pela IDE. Os três exemplos iniciais devem executar mesmo antes de concluir os exercícios.
